功能介绍

车牌自动识别
摄像头对准车牌，毫秒级返回车主、电话、部门等登记信息。
手动查询
键盘输入车牌号即可查询，适用于无摄像头的场景。
车辆管理
增删改查车辆、批量登记、批量导入图片，操作简单直观。
识别日志
所有识别记录可追溯，支持按时间/渠道/车牌搜索。
本地部署
数据全部存储在你的服务器，支持内网/局域网访问，不依赖外网。
科技感 UI
玻璃拟态 + 蓝青霓虹，暗色主题夜间使用更舒适。

使用说明

  1. 下载并安装 APK（首次需允许"安装未知来源"）。
  2. 打开 APP，初次进入会自动从服务器同步车辆数据。
  3. 将摄像头对准车牌，或点击右上角手动输入查询。
  4. 识别结果会同步记录到后台"识别日志"中。
