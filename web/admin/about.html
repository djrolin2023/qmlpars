车辆识别管理系统Admin

基于车牌图像自动识别的车辆出入管理系统，提供车辆信息录入、有效期管理、 识别记录追溯、OCR 通道配置与多部门协同管理能力，适用于园区、社区、单位的智能化车辆管控场景。

系统信息
系统版本—
前端框架原生 HTML / CSS / JavaScript
后端服务Node.js + Express
数据存储SQLite（轻量嵌入式）
识别能力百度 / 腾讯 OCR 通道
部署方式单机服务 / 内网运行
开源协议AGPL-3.0
开源仓库
GitHub github.com/djrolin2023/qmlpars Gitee gitee.com/dj_rolin/qmlpars

以 GitHub 为主仓库、Gitee 为镜像，任选其一克隆即可（内容一致）：

# GitHub（推荐）
git clone https://github.com/djrolin2023/qmlpars.git

# Gitee 镜像（GitHub 访问不便时使用）
git clone https://gitee.com/dj_rolin/qmlpars.git
一键部署

从 GitHub 拉取安装脚本一键安装本系统：

bash <(curl -sSL https://raw.githubusercontent.com/djrolin2023/qmlpars/main/install.sh)

从 Gitee 拉取安装脚本（GitHub 不便时）：

bash <(curl -sSL https://gitee.com/dj_rolin/qmlpars/raw/main/install.sh)

或先下载再执行：

wget -O install.sh https://raw.githubusercontent.com/djrolin2023/qmlpars/main/install.sh && bash install.sh
核心功能
车辆管理批量录入、部门归类、有效期与到期提醒
照片识别上传车辆照片自动识别车牌，支持点击 / 拖拽 / 粘贴
识别记录完整记录出入识别明细，支持检索与导出
OCR 配置灵活切换百度 / 腾讯识别通道与参数
部门权限按部门标签管理车辆，支持多部门归属
系统设置站点信息、LOGO 与基础参数集中配置
备份恢复导出 / 导入 .bin 加密备份，一键迁移新机器
移动端 APP（安卓）

系统提供安卓 APP，将门卫常用的「车牌识别」与「车辆管理」两个页面打包为独立安装包， 安装在门卫手机或平板上直接使用，避免微信端每次识别都要重新授权摄像头。

车牌识别摄像头实时识别车牌，自动判定内部 / 外部车辆并语音播报
车辆管理输入车牌查询内部车辆信息、有效期与历史识别记录
免授权登录安装时一次性授予摄像头权限，进入即直接识别
一键打包后台「APP 打包」页填写服务器地址即可生成 APK，无需开发环境

获取方式：以管理员身份登录后台 → 进入「APP 打包」→ 填写服务器地址、应用名、应用包名 → 点击开始打包， 完成后在下载处获取 APK 安装即可（打包出的 APP 内所有请求均指向所填写的服务器地址）。
