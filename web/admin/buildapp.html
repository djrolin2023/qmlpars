签名配置

签名证书用于给 APK 签名，同一证书才能覆盖升级。两种方式任选其一
📖 签名教程（点开/收起）

方式一 · 一键生成（推荐，最简单）
点击下方「一键生成签名证书」，系统会用默认或你填写的别名/密码立即生成自签名证书并可直接下载备份。 适合内部分发；如需上架应用商店也完全可用（商店只认证书不认谁生成的）。

方式二 · 上传自有证书
若你已有从别处（如 Android Studio / keytool）生成的 .keystore 或 .jks，直接上传即可，下方填写对应密码与别名。

⚠ 关键提醒
请妥善备份 qianming.keystore（或你生成的文件）。更换证书后旧用户将无法覆盖升级（需先卸载再装）。 密码仅在打包时使用、不保存于服务器，请自行记录。

本机手动生成命令（可选）：
keytool -genkey -v -keystore qianming.keystore -alias qianming -keyalg RSA -keysize 2048 -validity 10000

不填则用默认：别名 qianming / 密码 Qm@2026!Sign#K3y
点击上传签名证书（.keystore / .jks）
不传则使用「一键生成」或系统已有的证书
