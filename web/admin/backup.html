数据备份

仅备份后台填写的数据：车辆档案、识别记录、系统配置（含 OCR 密钥）。不含任何上传图片，体积小、轻量。
文件为 .bin 格式，可设密码加密（AES-256-GCM）。

自动备份设置

恢复备份

选择 .bin 数据备份文件并输入其密码（若有）。恢复会覆盖当前全部数据，系统会先把现有数据暂存到 backup/trash-* 目录，出问题可手动找回。

打包迁移

用于整机迁移到新服务器。打包内容 = 数据备份(.bin) + 全部上传图片（车辆照片 + 识别抓拍快照）。
生成 .zip（可加密），新机用 install.sh 部署系统后，将 zip 内的图片与数据拷回即可。
