百度 OCR 车牌识别

用于识别车牌的百度智能云「文字识别」服务（车牌识别接口）。

  1. 登录 百度智能云控制台 → 进入「文字识别」产品页。
  2. 在「应用列表」中创建应用（勾选「车牌识别」），获得 API Key 与 Secret Key。
  3. 将下方两值粘贴保存即可（密钥仅本机数据库存储，不对外传输）。

腾讯 OCR 备用通道

作为百度通道的备用识别源，使用腾讯云「OCR 文字识别」服务。

  1. 登录 腾讯云控制台 → 进入「文字识别 OCR」。
  2. 在「访问管理 → API 密钥管理」获取 SecretId 与 SecretKey（主账号或子账号密钥均可）。
  3. 粘贴保存后系统将自动启用该通道作为备用。
